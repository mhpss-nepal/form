# Previews for partner review (19 Nov 2026)

Two draft Layer 1 forms, published so partners can try them on their phones before the forms are wired to the reporting backend.

- `referral-directory.html` — Referral Directory: Service Mapping, with pin location; aligned with Tool 3B and Tool 4 of the multi-sectoral MHPSS assessment toolkit accompanying the IASC MHPSS MSP, and the Nepal Protection Cluster referral pathway categories.
- `grief-early-assessment.html` — Grief Early Assessment for field staff.

Both pages save entries only in the browser of the device that opens them. Nothing is sent to any server. They are not linked from the form directory and carry `noindex`.
